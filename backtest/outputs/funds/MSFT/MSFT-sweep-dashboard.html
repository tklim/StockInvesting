3 · Running years: how much evidence is each run judged on?

Running years = history depth − lookback — the out-of-sample window a run is actually scored on. A 4Y file with a 3Y lookback leaves just one year to test on; a 5Y file with a 1Y lookback leaves four. Same sweep, very different amounts of evidence.

4 · Correlation strength

Spearman rank correlation between excess annualized return and each numeric factor. Rank-based, so it catches any monotonic relationship, not just straight lines. Bars right of the line mean "more of this went with a better result".

5 · Return vs. risk

Excess annualized return against maximum drawdown. The upper-left quadrant is the one worth wanting: beats buy & hold with a shallower worst-case loss.

6 · What else tracks the result

The same runs against the four factors most likely to explain performance. A cloud with no tilt means that factor is not what separates a good run from a bad one.

7 · Is a good cell repeatable?

Every individual run in each cell that has at least three runs, ranked by median. A tight cluster means the search converges; a wide spread means the same settings can produce very different outcomes, and any single result from it is luck.
